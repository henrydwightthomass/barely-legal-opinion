# The Barely Legal Opinion — Issue 001

This build contains the live-ready static prototype for **The Barely Legal Opinion**.

## Pages
- `index.html` — homepage
- `new-kid-on-the-block.html` — Issue 001, **New Kid on the Block**
- `styles.css` — responsive editorial design
- `script.js` — mobile navigation

## Sources
Issue 001 includes a **Sources & Further Reading** section after the article body. The body itself contains no inline citation links so the piece reads like an opinion column rather than a research paper.

## Preview
Open `index.html` in a browser.

## Publish
The folder can be deployed as-is to Netlify, Vercel, GitHub Pages, or another static host. The subscribe form is visual only until an email provider is connected.
